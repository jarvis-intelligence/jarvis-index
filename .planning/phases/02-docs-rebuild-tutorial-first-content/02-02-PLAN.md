## Response-key contract (embed-quality copy of 02-RESEARCH Product Truth §1 — executors verify against source before use)

| Tool | Response keys |
|------|---------------|
| `documentSymbols(repo, path)` | `{"path", "symbols": [{symbol, displayName, kind, range}], +flat freshness}` |
| `goToDefinition(repo, symbol)` | `{"symbol", "resolvedSymbol"?, "definitions": [Location], +flat freshness}` |
| `findReferences(repo, symbol)` | `{"symbol", "resolvedSymbol"?, "references": [Location], +flat freshness}` |
| `callHierarchy(repo, symbol)` | `{"symbol", "resolvedSymbol"?, "incomingCalls": [{symbol: {symbol, displayName, kind}, location: Location}], "outgoingCalls": [...], +flat freshness}` |
| `typeHierarchy(repo, symbol)` | success: `{"symbol", "resolvedSymbol"?, "supertypes", "subtypes", +flat freshness}`; unavailable: error + `"symbol"` + flat freshness |
| `getIndexStatus(repo, repo_path=None)` | `{"repo", "indexed", "status", +flat freshness, "searchCoverage": {expected, indexed, complete} \| null, "searchCoverageReason"?}` |
| `searchCode(query, repo=None)` | `{"query", "hits": [{"repo","path","lineNumber","lineText"}], "total"}` — no freshness fields |
| `semanticSearch(repo, query, limit=10)` | entries `{"repo","filePath","startLine","endLine","symbolName","content","score","sources"}` + optional top-level `"warning"`; top-level keys MUST be confirmed from ../jarvis/src/jarvis/semantic.py:340-380 before finalizing (RESEARCH assumption A4) |
| `blastRadius(repo, symbol_or_package)` | `{"repo", "symbolOrPackage", "dependents": [{repo, name, hops}], +flat freshness}` — freshness always "unknown" |

"+flat freshness" = the five fields spread flat at the response top level: `"commit"`, `"generated_at"`, `"stale"`, `"freshness"` (one of `"fresh"|"stale"|"unknown"`), `"checked_at"`. A `Location` is `{"path": "...", "range": {"start": {"line": N, "character": N}, "end": {"line": N, "character": N}}}`. `resolvedSymbol` appears only when resolution changed the input.
