    Ensure Docker daemon is running (open Rancher Desktop). Then:
    ```bash
    mkdir -p public/assets/asciinema
    docker run --rm -it --platform linux/amd64 \
      -v "$PWD/public/assets/asciinema:/output" \
      python:3.13-slim bash -c '
      apt-get update -qq && apt-get install -y -qq asciinema curl git && \
      cd /tmp && \
      mkdir toy-repo && cd toy-repo && \
      echo "def greet(name): return f\"Hello, {name}\"" > greeter.py && \
      git init && git add . && git commit -m "init" && \
      cd /tmp && \
      asciinema rec -o /output/cold-install.cast bash -c "
        echo \"=== jarvis cold-install recording ($(date -u +%Y-%m-%dT%H:%M:%SZ)) ===\" && \
        echo \"=== Platform: linux/amd64 (python:3.13-slim) ===\" && \
        curl -fsSL https://raw.githubusercontent.com/jarvis-intelligence/jarvis-index/main/setup.sh | sh && \
        pip install uv && \
        uv tool install jarvis-mcp && \
        jarvis index /tmp/toy-repo && \
        jarvis status toy-repo
      "'
    ```

    Verify the .cast file exists and is non-empty (should be 50-200 KB for a 3-5 min session).
