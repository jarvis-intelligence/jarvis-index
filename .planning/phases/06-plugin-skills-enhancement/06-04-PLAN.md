| Boundary | Description |
|----------|-------------|
| command/agent markdown → agent execution | `plugin/commands/*.md` and `plugin/agents/jarvis-navigator.md` are instruction text an installed client executes, including tool calls and shell fallbacks |
| manifest `$schema` URL → editor / CI schema fetch | a declared schema URL is fetched by editors and any JSON-schema tooling that honours it |
